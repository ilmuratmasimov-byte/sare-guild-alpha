# Security

Не добавляйте в репозиторий keystore, пароли, токены, `key.properties`, `local.properties` и другие секреты.

Release keystore хранится только у владельца проекта и в GitHub Actions Secrets в Base64. Если signing key когда-либо попал в публичную историю Git, его нужно считать скомпрометированным и заменить до распространения APK.

Сообщения об уязвимостях не следует публиковать в открытых Issues вместе с секретами или персональными данными.
